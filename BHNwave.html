BHNwave

A beep-tone cipher language. Type a message → encode (direct or encrypted) → transmit as tones &/or speak aloud → record it → play it into the decoder to recover the text. 100% offline.
🎲 For fun / puzzles / shared codes. A toy cipher — not for real account passwords (a recording can be decoded by anyone who has it).
